# Pharlux documentation

This is the documentation for **Pharlux v1.2.0** &mdash; a single statically-linked Rust binary delivering unified OpenTelemetry-native observability for small teams. Mirrored from the [`pharlux/docs/`](https://github.com/Veltara-Works/pharlux/tree/v1.2.0/docs) directory in the main repo. The repo is the source of truth; this site is regenerated when a new version ships.
